# Студия Лексикон

Открытый учебный сайт по орфографии, пунктуации и стилистике русского языка для 8–11 классов.

Сайт: https://pavelaleks.github.io/studiya-leksikon/

## Как устроено

- `data/orthography.json` — правила орфографии (по одному объекту на правило).
- `data/punctuation.json` — каталог глав пунктуации (наполняется следующим этапом).
- `data/stylistics.json` — каталог глав стилистики.
- `data/exercises.json` — тесты, вставка буквы, списывание.
- Страница «Модератору» (`#/admin`) — пароль `leksikon` (смените в `js/config.js`).

Формат пропуска в списывании: `{{о}}` — ученик вписывает букву или целое написание.

Теория написана как школьные карточки студии. Ссылки на параграфы справочника Розенталя ведут на внешний сайт и даны для углубления; полный текст справочника сюда не копировался.

## Локальный просмотр

Нужен любой статический сервер (браузер не загрузит JSON с `file://`):

```bash
npx --yes serve .
```
