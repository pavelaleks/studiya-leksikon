# Студия Лексикон

Открытый учебный сайт по орфографии, пунктуации и стилистике русского языка для 8–11 классов.

Сайт: https://pavelaleks.github.io/studiya-leksikon/

## Как устроено

- `data/orthography.json` — орфография: § 1–62 и разделы ъ/ь, предлоги, союзы, междометия, иностранные слова.
- `data/punctuation.json` — пунктуация: § 1–72.
- `data/stylistics.json` — стилистика: § 139–213.
- Банк заданий (ЕГЭ и тесты) в git не лежит: в репозитории только шифрованный `data/bank.enc`.

Формат выделения в теории: `{а}` орфограмма, `{при-|p}` приставка, `{гор|r}` корень, `{енн|s}` суффикс, `{,|z}` знак, `{отрасль|x}` исключение.

Формат пропуска в списывании: `{{о}}` — ученик вписывает букву или знак.

## Локальный просмотр

Нужен любой статический сервер (браузер не загрузит JSON с `file://`):

```bash
npx --yes serve .
```
